🔐 Login Form Validation
- A simple Login Form Validation project built using HTML, CSS, and JavaScript.
- This project validates whether the password and re-enter password fields match before allowing a successful login.

🚀 Features
- User login form with username and password fields
- Password and re-enter password validation
- Error message display for mismatched passwords
- Success alert on correct validation
- Simple and clean UI

🛠️ Technologies Used
- HTML – Form structure and input fields
- CSS – Basic styling and layout
- JavaScript – Form validation and event handling

📂 Project Structure
form-validation/
│
├── index.html      # HTML structure
├── style.css       # CSS styling
└── script.js       # JavaScript validation logic

📋 How It Works
- User enters username, password, and re-enter password
- On clicking the Submit button:
- JavaScript compares password values
- If passwords do not match, an error message is shown
- If passwords match, a success alert is displayed
- Form is reset after validation

▶️ How to Run the Project
- Download or clone the repository
- Open index.html in any modern web browser
- Enter the required details and click Submit
